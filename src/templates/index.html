How this ranking works

This page scores AI coding tools by public usage signals, not benchmarks or surveys. Every signal is collected once per day from public APIs and snapshotted into the repository's data/snapshots/ directory, so the entire history is auditable.

GitHubstars, forks, commits pushed to the tool's own repo in the trailing 30 days, and commit-message mentions across GitHub. Hacker Newscomment-mention counts for the trailing 7 and 30 days (Algolia API). Redditmentions in the trailing 7 and 30 days (OAuth search, newest-first, capped at 1000). VS Code Marketplaceextension installs, downloads, and weekly trending. Open VSXopen-source marketplace download count. JetBrainsofficial plugin downloads.

Each metric is min-max normalized across the tracked tools to 0–100. Install base blends cumulative reach (stars, installs, downloads, 30d mention volume). Momentum blends 30-day deltas and recent activity (stars gained, installs gained, commits, 7d mention volume). Drag the weight sliders to re-weight — the ranking recomputes instantly in your browser.

Coverage penalty. Missing sources count as zero in the composite — a tool that only has data for some sources is capped by the weight those sources carry (the denominator is the full weight sum). Rows with incomplete data show a n/m sources badge; hover it for details. This prevents tools with a single loud signal (e.g. only Hacker News mentions) from topping the ranking.

Caveats. These are relative signals, not absolute usage. Ambiguous names (cursor, windsurf, cline, devin, aider, continue) are disambiguated with query phrases and still carry noise. GitHub commit search is noisy (AI-generated commits) and is not part of the composite score. Tools without an official plugin/extension show – for that source. Counts are server-reported install/download totals, not active users.

Raw data & tool requests

Every day the collector records each tool's metrics from the public APIs above and stores them as an auditable snapshot — one JSON file per day, one line per tool. Anyone can inspect or download the raw numbers behind this ranking.
