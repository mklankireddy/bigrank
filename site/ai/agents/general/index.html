How this ranking works

This page scores open-source general-purpose AI agents by project health and momentum — not hype. Every signal is collected once per day from public GitHub/HN/Reddit APIs and snapshotted into data/general-purpose-agents_snapshots/, so history is auditable. The point: many agent projects look alive until you try them — commit and issue velocity reveal which ones are actually being maintained.

Signals

Activity commits and issues opened/closed in the trailing 30 days. Adoption stars, forks created in the last 30 days, watchers, and HN/Reddit mentions (30d). Freshness time since the last commit, plus the repo's archived flag.

Scoring

  • Activity — min-max normalized blend: commits (40), issues opened (30), issues closed (30).
  • Adoption — min-max normalized blend: stars (25), forks 30d (20), watchers (10), HN 30d (25), Reddit 30d (20).
  • Overall rank — Activity 50% + Adoption 50%.
  • Missing sources count as zero (coverage penalty), so sparse data drags a score down.

Freshness badge

  • Archived — the repository is archived (no further development).
  • Active — committed within 7 days. Steady — within 30. Slowing — within 60. Stale — 60+ days.

Pricing tags

The Free / Freemium / Paid tag next to each agent is hand-maintained from the project's official pricing page — an approximation, not a metric, and it does not affect the score. Free = no payment required (may need your own LLM/API key). Freemium = a usable free tier, but limits/features push you toward a paid plan. Paid = subscription required to use it at all.

Caveats

  • These are project-health signals, not product quality.
  • A big open-issue backlog (e.g. 20k+) can mean high interest, not a broken project.
  • The "ease of running" note is hand-maintained and rough, not a metric.
  • GitHub dependents and Discord member counts are not yet included (no stable public API).
