How this ranking works

This page scores AI coding tools by public usage signals, not benchmarks or surveys. Every signal is collected once per day from public APIs and snapshotted into the repository's data/snapshots/ directory, so the entire history is auditable.

Data sources

GitHubstars, forks, commits pushed to the tool's repo in the trailing 30 days, and commit-message mentions.
Hacker Newscomment mentions for the trailing 7 and 30 days (Algolia API).
Redditmentions for the trailing 7 and 30 days (OAuth search, newest-first, capped at 1000).
VS Code Marketplaceextension installs, downloads, and weekly trending.
Open VSXopen-source marketplace download count.
JetBrainsofficial plugin downloads.

Scoring

Each metric is min-max normalized across the tracked tools to 0–100. Drag the weight sliders to re-weight — the ranking recomputes instantly in your browser.

  • Install base — cumulative reach: stars, installs, downloads, and 30d mention volume.
  • Momentum — recent activity: 30-day deltas, commits, and 7d mention volume.

Coverage penalty

Missing sources count as zero in the composite — a tool with data for only some sources is capped by the weight those sources carry (the denominator is the full weight sum). Rows with incomplete data show a n/m sources badge; hover it for details. This stops tools with a single loud signal (e.g. only Hacker News mentions) from topping the ranking.

Pricing tags

The Free / Freemium / Paid tag next to each tool is hand-maintained from each product's official pricing page — an approximation, not a metric, and it does not affect the score. Free = no payment required (may need your own LLM/API key). Freemium = a usable free tier, but limits/features push you toward a paid plan. Paid = subscription required to use it at all.

Caveats

  • These are relative signals, not absolute usage.
  • Ambiguous names (cursor, windsurf, cline, devin, aider, continue) are disambiguated with query phrases and still carry noise.
  • GitHub commit search is noisy (AI-generated commits) and is not part of the composite score.
  • Tools without an official plugin/extension show – for that source; counts are server-reported totals, not active users.
Raw data & tool requests

Every day the collector records each tool's metrics from the public APIs above and stores them as an auditable snapshot — one JSON file per day, one line per tool. Anyone can inspect or download the raw numbers behind this ranking.
