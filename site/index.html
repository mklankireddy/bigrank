Raw data & tool requests

Every day the collector records each ranking's metrics from public APIs and stores them as auditable snapshots — one JSON file per day, one line per entry, under data/coding-agents_snapshots (coding agents), data/general-purpose-agents_snapshots (general-purpose agents), and data/local-model-runner_snapshots (local model runners). Anyone can inspect or download the raw numbers behind these rankings.
